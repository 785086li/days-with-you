# Days With You

一个可以记录纪念日、正计时和倒计时的私密个人网站。页面不依赖框架或数据库，直接打开 `index.html` 就能使用，也可以部署到 GitHub Pages、Cloudflare Pages、Vercel 等静态托管服务。

## 初始密码

```text
0520
```

进入网站后，点击右上角头像进入“网站设置”，可以修改主页文字和访问密码。

## 功能

- 密码进入，同一浏览器标签页内保持登录，关闭标签页后重新验证
- 正计时和倒计时，精确到秒
- 每年重复的生日、周年纪念日
- 设置首页主卡片纪念日
- 纪念日新增、编辑、删除和分类筛选
- 修改首页称呼、标题、介绍和“关于”文案
- 在网站设置中立即重新锁定
- 所有纪念日与文字保存在当前浏览器的 `localStorage`
- 桌面端和手机端响应式布局

## 关于密码保护

当前版本是纯静态网站，密码校验和数据都保存在浏览器本地。它能阻止普通访客直接进入页面，但不能提供真正的服务端安全保护：懂技术的人仍可能通过浏览器开发者工具读取本地数据或绕过前端逻辑。

如果以后要把这个网站公开到互联网，并存放真实的私密文字或照片，建议增加服务端登录接口和数据库，把密码验证与数据读取都放到服务端完成。

## 公开主页与搜索收录

当前页面已经按“公开主页 + 密码入口”的方式准备：访客可以打开网址看到欢迎页和密码输入框，输入正确密码后才进入纪念日、关于我们和网站设置。搜索引擎可以收录公开欢迎页。

部署到 GitHub Pages、Cloudflare Pages 或 Vercel 时：

1. 上传 `index.html`、`app.js`、`styles.css`、`robots.txt` 和 `sitemap.xml`。
2. 把 `robots.txt` 与 `sitemap.xml` 中的 `https://YOUR-DOMAIN.example/` 替换成实际网址。
3. 部署完成后，把实际网址提交到 Google Search Console 或 Bing Webmaster Tools。

目前密码校验与纪念日数据仍在浏览器本地，适合个人使用和小范围分享。若要保护高敏感内容，需要把登录验证和数据存储迁移到服务端数据库。

## 修改初始密码或恢复示例数据

密码可以在网站设置中修改。如果忘记密码，需要清除该站点在浏览器中的本地存储，网站会恢复为初始密码和示例纪念日。浏览器开发者工具的 Application / Storage 面板可以完成清除操作。
